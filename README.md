PicturesqueOS is a project to be used with a raspberry pi pico 2WH, and an E-ink display. It uses a waveshare Pico e-Paper 4.2 V2 display and syncs the time via NTP.

https://www.waveshare.com/wiki/Pico-ePaper-4.2

Don't know if a normal pi pico w would work, but it definetely should. But i used a pico 2WH since i had it laying around.
